═══════════════════════════════════════════════════════════════════════════════
DATA FLOW SUMMARY
═══════════════════════════════════════════════════════════════════════════════

1. USER ACTION           →  Frontend sends request
2. API ENDPOINT          →  Backend receives request
3. DATABASE UPDATE       →  Data saved to PostgreSQL
4. SMS TRIGGER           →  twilioService.notifyX()
5. TWILIO API            →  SMS sent via Twilio
6. PHONE DELIVERY        →  User/Driver receives SMS
7. RESPONSE              →  Success returned to frontend
8. LOGGING               →  Console logs for debugging

PARALLEL OPERATIONS:
├─ In-app notification   (createNotification)
├─ SMS notification      (twilioService)
└─ Socket.io event       (real-time update)

All three happen simultaneously!

PHONE NUMBER REQUIREMENTS
═══════════════════════════════════════════════════════════════════════════════

✅ VALID FORMATS:
   +917454061975       (India)
   +19876543210        (USA)
   +447911123456       (UK)

❌ INVALID FORMATS:
   917454061975        (missing +)
   +91 745 406 1975    (has spaces)
   +91-7454061975      (has hyphens)
   7454061975          (missing country code)

VALIDATION:
   • Must start with +
   • 10-15 digits total
   • No spaces or special chars
   • Country code required
